# دعوة زفاف محمد أديب طويل ورزان بطايحي

نسخة ثابتة من قالب باب الفرح لعرض الدعوة على GitHub Pages.

عدّل أسماء العروسين وموعد المناسبة ونصوصها وروابطها ومسارات الأصول في `config.js`. رابط تأكيد الحضور يستخدم واتساب ورقم `event.contactPhone` الحالي من الدعوة المرجعية؛ يجب استبداله برقم الاستقبال الفعلي قبل استقبال الردود. لا تخزن GitHub Pages الردود أو تعرض تهاني الزوار الجدد، لأن واجهة هلاهيل الأصلية غير متاحة لهذا الموقع.

للمعاينة المحلية: `python3 -m http.server 8765` ثم افتح `http://localhost:8765/`.
